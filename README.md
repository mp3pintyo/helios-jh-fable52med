# A Huang-akta

Görgethető nyomozati oldal a 2026. novemberi Nvidia–Jensen Huang-ügyről, hat nyelv sajtójából összerakva.
A 3D hátteret a Helios böngészős grafikus motor rendereli (WebGPU).

Élő oldal: https://mp3pintyo.github.io/helios-jh-fable52med/

Helyi futtatás: `python -m http.server 8137`, majd http://localhost:8137/
A jelenet újragenerálása: `python tools/build_scene.py`
